Azure Function · RESORG Projektabwicklung

Rahmenvertrag Vorbefüllung

Wird in der Canvas App ein neues Rahmenvertragsprojekt angelegt, richtet diese Funktion den Projektordner in SharePoint ein. Sie kopiert den Musterordner, füllt die PDF-Formulare mit den Projektdaten aus und erstellt zusätzliche Dokumente (z. B. das Vonovia-LV im GAEB-Format), die je Bst.-Nr. in einer SharePoint-Liste hinterlegt sind.

Funktion RahmenvertragVorbefuellung Python · Functions-Runtime ~4 Auslöser HTTP POST, Function Key SharePoint über Microsoft Graph
Architektur

Komponenten und ihr Zusammenspiel

  1. Die Canvas App sendet die Projektdaten (Adresse, Bst.-Nr., Ang.-Nr., Auftraggeber, Ersteller, …) als JSON an die Funktion.
  2. Die Funktion meldet sich mit dem Client Secret der App-Registrierung bei Entra ID an und erhält ein Microsoft-Graph-Token.
  3. Sie kopiert den Musterordner aus Templates nach Rahmenverträge und füllt die PDF-Formularfelder, deren Namen zu den Feldern der Anfrage passen.
  4. Sie liest LV_Vorlagen_Rahmenverträge. Für jede Zeile mit der Bst.-Nr. aus der Anfrage füllt sie die verlinkte Vorlage aus und speichert sie im verlinkten Zielordner.
  5. Sie gibt den Status, die erstellten Dateien und einen Link auf den neuen Projektordner (folder_url) an die Canvas App zurück.

Funktion und App-Einstellungen

Funktion RahmenvertragVorbefuellung · HTTP POST · Authentifizierung „function“
App-EinstellungZweck
tenant_id, client_id, client_secretApp-Registrierung in Entra ID, mit der das Graph-Token geholt wird
resourcePräfix des Token-Scopes (Microsoft Graph)
site_urlSharePoint-Site im Graph-Format, 118016aplus.sharepoint.com:/sites/Projektabwicklung
source_libraryBibliothek mit dem Musterordner (Templates)
source_folderMusterordner innerhalb dieser Bibliothek
target_libraryBibliothek für die Projektordner (Rahmenverträge)

Die App-Registrierung braucht eine Graph-Anwendungsberechtigung, um Templates und die Konfigurationsliste zu lesen und in Rahmenverträge zu schreiben (z. B. Sites.ReadWrite.All oder Sites.Selected mit Freigabe auf die Site).
